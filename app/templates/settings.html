企业微信推送

库存出入库、预警自动推送至企业微信

{% if wechat_configured %} 已配置 {% else %} 未配置 {% endif %}
配置说明
  1. 登录 企业微信管理后台
  2. 进入「我的企业」→ 获取「企业ID」(CorpID)
  3. 进入「应用管理」→ 创建应用 → 获取「AgentId」和「Secret」
  4. 在 Railway/Render 后台添加以下环境变量：
WECHAT_CORP_ID=你的企业ID WECHAT_AGENT_ID=你的应用ID WECHAT_SECRET=你的应用密钥 WECHAT_TO_USER=@all # @all表示全员，或填成员ID如：ZhangSan|LiSi
